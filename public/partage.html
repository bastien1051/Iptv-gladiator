IPTV Gladiator

Installer

Lecteur gratuit pour le téléphone et le navigateur du téléviseur. Les chaînes publiques sont déjà dans l’application.

Android

Téléchargez l’application, puis autorisez l’installation depuis cette source si le téléphone le demande.

Télécharger l’APK

iPhone

  1. Ouvrez l’application dans Safari.
  2. Touchez le bouton Partager.
  3. Choisissez Sur l’écran d’accueil, puis Ajouter.

L’icône IPTV Gladiator s’ouvre ensuite comme une application.

Téléviseur Samsung ou LG

Ouvrez le navigateur Internet du téléviseur et saisissez cette adresse :

https://bastien1051.github.io/Iptv-gladiator/

Les flèches déplacent le cadre, OK valide, Retour revient. Pour une liste personnelle, utilisez Ajouter mon abonnement. Si le téléviseur bloque la liste, importez le fichier M3U : ce site ne peut pas la relayer.
